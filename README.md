## 竞赛要点

- 初赛 **2026 年 11 月 14 日（周六）9:00—11:30**，150 分钟
- **初赛只考高等数学**（不考线性代数，线代只在决赛考且占 20%）
- 卷面结构（近三届一致）：**填空 5×6=30 分 + 解答 5×14=70 分**
- 非数学A类 = 理工类；专业代码 07/08 的考生只能报 A 类
- 三届真题考点分布：多元积分 27%、极限 20%、级数 17%、多元微分 13%、微分方程 10%、不等式证明 10%、空间几何 10%

## 关于真题 PDF 的说明

第 15、16 届真题 PDF 的**文字层被字体混淆处理过**：删除了 `ToUnicode` 表、`/Widths` 全改为 1000、
字体 `cmap` 为空、字形名写入私用区（`uniF002` 这类）。第 17 届为纯扫描图片。

因此本资料中的真题原文通过以下方式还原，**已按试卷原图逐页核对**：

1. **字形轮廓指纹**：内嵌子集字体携带真实字形轮廓，用 fontTools 提取轮廓点位做指纹，
   比对系统宋体（`simsun.ttc`）的轮廓反查 Unicode；
2. **字形名反查**：字形名 `uniF0XX` 中的 `XX` 即原字符码；

公式部分均经 **KaTeX 语法校验**，关键结果用符号计算（sympy）与高精度数值（mpmath）独立复算。

## 使用建议

1. 先读考点总结，确认考试范围与自己的薄弱章节；
2. 按阶段学讲义，每学完一阶段立即做对应题集（闭卷、计时）；
3. 错题回到讲义对应小节，把结论补进题集末尾的「高频易错点清单」；
4. 最后 1.5 周掐时间做三届真题（每套 150 分钟，闭卷）。
